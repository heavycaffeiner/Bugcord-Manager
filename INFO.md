## Backing up Bugcord

Note: This section is about the app installation itself, not the installed plugins, themes, and settings.

The patched Bugcord APK is tailored to the current device's Android version and CPU architecture.
Reusing a patched Bugcord APK from one device on another will likely break. Backing up and
restoring on another device will likely break.

Install Bugcord **directly via Manager** on the device you wish to use it on.
